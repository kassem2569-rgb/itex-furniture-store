ITEX Furniture & Electronics — demo storefront
Files:
- index.html: customer storefront with product filters, cart, checkout form and WhatsApp order handoff.
- admin.html: local demo admin to add/edit/delete products and review local orders.
- images/: supplied product images.

IMPORTANT LIMITATIONS BEFORE PUBLIC LAUNCH
1. This is a static front-end demo. Product and order data use browser localStorage, so it is not a shared database and admin changes do not sync across customers/devices.
2. Checkout creates a local order record and opens WhatsApp for the customer to send the order. The site cannot confirm a WhatsApp message was sent.
3. M-Pesa is a payment preference only; no money is charged. Live M-Pesa requires a secure backend and Safaricom Daraja credentials.
4. A real launch needs hosting/domain, backend/database, protected admin authentication, server-side order storage, validation, privacy policy and payment integration.
5. Prices are demo prices and must be verified by ITEX before publishing.
